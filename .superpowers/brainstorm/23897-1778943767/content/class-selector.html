How does the Class selector work?

Students are in Class 6–12. When they open the Roadmap, which subjects should they see?

A

Auto-filtered by their enrolled class

A Class 9 student sees only Class 9 subjects. No class picker shown — derived from their profile.

B

Class switcher tab at the top

Student can manually switch between classes (e.g. browse Class 10 content even if enrolled in Class 9) — useful for advanced learners.

C

Show all classes in a dropdown / sidebar

Full curriculum browser — every class, every subject visible. Locked topics shown but not accessible until unlocked.
